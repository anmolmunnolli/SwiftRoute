SwiftRoute learns between calls, never during one, and every change has to prove itself first. An improvement agent reads failures through SwiftRoute's MCP server and writes short lessons for the phone agent. A lesson is kept only if the eval suite scores higher with no new safety failures. Confirmed read-backs teach the tracking-number decoder which characters speech recognition really confuses. Policy rules and model weights are never changed by these loops.

Phase 6a: a measured negative result

Cutting prompt tokens by a third made the 3B no faster and no more accurate. Ollama reuses the cached prefix of the prompt, so a stable prompt matters more than a short one, and the cost left over is decoding. The same four scenarios failed in every prompt variant, which points at model capacity. That is why the next step is distillation, not more prompt work.
